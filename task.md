Техническое задание
Разработка сайта студии акробатики «Планета UP»
Заказчик: Планета UP 
Ссылка на группу ВК (референс контента): https://vk.ru/planetaupacro

1. Общая информация о проекте
Тип проекта: одностраничный/многостраничный сайт-визитка студии акробатики с формой онлайн-записи.
Цель сайта: привлечение новых учеников (взрослых и детей) на пробное занятие, представление студии, повышение доверия за счёт отзывов, фото и информации о тренерах.

Целевая аудитория:
Взрослые, рассматривающие акробатику как новое хобби/фитнес-направление
Родители, выбирающие секцию для ребёнка
Тип сайта: SPA (Single Page Application) на React, с отдельными маршрутами (страницами) для крупных разделов; технически — статическая сборка (JAMstack), без собственного сервера с базой данных.

3. Структура сайта (карта разделов)
1) Главная — hero-блок в космическом стиле + форма записи на пробное занятие + краткие анонсы (тизеры) остальных разделов
2) Взрослым — описание групп/направлений для взрослых
3) Детям — описание групп/направлений для детей
4) Абонементы — тарифы и условия
5) Наша команда — тренеры
6) Галерея — фотографии с занятий
7) Жизнь коллектива — соревнования, сборы, мероприятия
8) Отзывы
9) Частые вопросы (FAQ)
10) Контакты — адрес, карта, соцсети, форма записи (дублируется)
Навигация: закреплённое меню (header) с якорными ссылками на главной + отдельные страницы для «Взрослым» и «Детям» (если объём контента большой) или анкоры на одной странице — уточняется на этапе прототипа.

4. Функциональные требования по разделам
4.1 Главная / Hero
Полноэкранный первый блок в тёмно-синих/фиолетовых тонах, «космическая» стилистика (звёзды, мягкое свечение, возможна лёгкая parallax-анимация при скролле)
Заголовок + короткий подзаголовок с УТП студии
Форма записи на пробное занятие видна без скролла (см. п. 4.9)
Плавный переход (градиент) от тёмного hero-блока к светлой части сайта
Блок с краткими анонсами разделов (карточки «Взрослым» / «Детям» / «Абонементы» / «Отзывы» и т.д.) со ссылками на соответствующие разделы
4.2 Взрослым / Детям
Список групп/направлений с описанием (уровень, направление, возрастная категория для детского раздела)
Расписание (таблица или карточки по дням недели)
Фото/иллюстрация на каждую группу
Кнопка «Записаться» на каждую карточку группы, ведущая к форме записи с предзаполненным полем «группа»
4.3 Абонементы
Карточки тарифов: название, стоимость, что включено, условия заморозки/переноса
Кнопка «Купить»/«Записаться» на каждый тариф
4.4 Наша команда
Карточки тренеров: фото, имя, специализация, краткое описание опыта
Опционально: ссылка на соцсети тренера
4.5 Галерея
Сетка фотографий с открытием в лайтбоксе (увеличенный просмотр, листание стрелками)
Фильтрация по категориям: «Взрослые» / «Дети» / «Соревнования» (опционально, по согласованию)
Ленивая загрузка изображений (lazy loading) для скорости
4.6 Жизнь коллектива
Блог-подобная лента: соревнования, сборы, праздники, закулисье
Формат: карточки с фото + короткий текст, дата события
4.7 Отзывы
Карточки с текстом отзыва, именем, (опционально) фото
Возможность добавления ссылок на внешние отзывы (ВК, Яндекс.Карты)
4.8 FAQ
Аккордеон вопрос-ответ (5–10 вопросов на старте, с возможностью добавления новых)
4.9 Форма записи на пробное занятие
Обязательные поля:
Имя
Телефон
Направление (взрослый/ребёнок, конкретная группа — предзаполняется, если пришли с карточки группы)
Удобное время/день (выпадающий список или текстовое поле)



Технические требования:
Валидация полей на клиенте (обязательность, формат телефона)
Защита от спам-ботов (простая honeypot-защита или капча)
При отправке: уведомление приходит заказчику на e-mail и/или в Telegram (канал/бот уточняется отдельно)
Пользователю после отправки показывается экран/сообщение об успешной отправке
Хранение заявок: минимум — пересылка в мессенджер/почту; опционально — таблица в Google Sheets через интеграцию
4.10 Контакты
Адрес, карта (Яндекс.Карты/Google Maps виджет)
Ссылки на соцсети (ВК и др.)
Повтор формы записи
5. Требования к дизайну
Первый экран (hero): тёмно-синие/фиолетовые тона, космическая эстетика (звёздное небо, туманности, мягкое свечение элементов)
Переход: плавный градиент от тёмного hero к светлым тонам остального сайта
Остальные разделы: светлая палитра, читаемая типографика, воздушная вёрстка
Единый стиль карточек, кнопок, иконок по всему сайту
Адаптивная типографика и отступы (mobile-first подход)
Дизайн-макет согласуется на этапе прототипа (Figma или аналог) до начала вёрстки — отдельным этапом









6. Технологический стек
Frontend:
React 18 + Vite
react-router-dom — маршрутизация
Tailwind CSS — стилизация, адаптивность
Framer Motion — анимации (звёздный фон, переходы между блоками)
Radix UI / Headless UI — аккордеон (FAQ), модальные окна
react-hook-form + zod — форма записи и валидация
Библиотека лайтбокса для галереи (например, yet-another-react-lightbox)
Backend:
Serverless-функция (Vercel Functions / Netlify Functions) или сторонний сервис приёма форм
Отправка уведомлений на e-mail (Resend/SendGrid) и/или в Telegram через Bot API
Инфраструктура:
Хостинг: Vercel или Netlify (бесплатный тариф)
Домен: регистрация отдельно (см. раздел 11)
Аналитика: Яндекс.Метрика

7. Нефункциональные требования
Адаптивность: корректное отображение на устройствах от 320px (мобильные) до 1920px+ (десктоп)
Браузеры: актуальные версии Chrome, Safari, Firefox, Edge; мобильные Safari/Chrome
Производительность: оптимизация изображений (сжатие, современные форматы типа WebP), ленивая загрузка, показатель Lighthouse Performance не ниже 80 на мобильной версии
SEO: мета-теги (title, description) на каждую страницу, семантическая разметка, sitemap.xml, robots.txt
Доступность (a11y): базовые требования — альтернативные тексты для изображений, достаточный контраст текста, навигация с клавиатуры для формы

8. Хостинг и домен
Домен регистрируется на имя заказчика (важно для владения активом) — заказчик получает данные доступа к панели регистратора
Хостинг на Vercel/Netlify — заказчик получает доступ к аккаунту проекта (или отдельный аккаунт студии, куда разработчик даёт доступ)
SSL-сертификат — подключается автоматически средствами хостинга (бесплатно)

9. Зона ответственности сторон
Заказчик предоставляет:
Тексты по всем разделам (описания групп, абонементов, тренеров, отзывы, вопросы для FAQ)
Фотографии в хорошем качестве для галереи, hero-блока, карточек тренеров
Логотип (если есть) в векторном или высоком разрешении
Контакты, ссылки на соцсети, реквизиты для формы уведомлений (e-mail/Telegram)
Согласование дизайн-макета в оговорённый срок (задержка согласования сдвигает срок сдачи)
Исполнитель предоставляет:
Прототип структуры (wireframe) и дизайн-макет ключевых экранов на согласование
Готовый код сайта, размещённый на хостинге
Краткую инструкцию по работе с CMS для самостоятельного редактирования контента
Гарантийное исправление багов, после их выявления на production.
